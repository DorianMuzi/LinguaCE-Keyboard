## Description courte (80 max)
Clavier tchétchène latin et cyrillique, avec suggestions. Sans accès Internet.

## Description complète (4000 max)
Écrivez le tchétchène en alphabet latin ou en cyrillique, sur un clavier conçu pour cette langue.

LinguaCE Keyboard est un projet de l'écosystème LinguaCE, qui soutient l'apprentissage et l'écriture du tchétchène.

ÉCRIRE LE TCHÉTCHÈNE CORRECTEMENT
• Alphabet latin tchétchène : appui long sur une lettre pour ses variantes (x → ẋ, s → ş, c → ċ, ç → ç̇, n → ŋ…).
• Clavier cyrillique avec la touche Ӏ (paloçka).
• La touche КИР / LAT passe du latin au cyrillique ; appui long pour changer de clavier.
• QWERTY ou AZERTY pour le clavier latin.
• Chiffres par appui long sur la rangée du haut, comme Gboard.
• Le w reste disponible pour les mots d'origine étrangère.

DES SUGGESTIONS QUI APPRENNENT
• Suggestions de mots à partir d'une liste de base et des mots que vous tapez, appris sur votre téléphone seulement.
• Tapez sans accents : « noxciyn » propose « noxçiyŋ ».
• Dictionnaire personnel : voir, ajouter et supprimer des mots, ou tout effacer.

CONFORT
• Thème clair, sombre ou celui du téléphone ; touches petites, normales ou grandes.
• Panneau emoji avec récents (appui long sur la virgule).
• Barre d'outils : réglages, emoji, annuler et coller.
• Majuscule automatique et double espace pour un point.
• Son et vibration des touches, au choix.
• Compatible TalkBack.

PRIVÉ PAR CONCEPTION
• Aucune permission, pas même Internet : le clavier ne peut rien envoyer.
• Aucune publicité, aucune mesure d'audience, aucun suivi.
• Code ouvert (Apache 2.0) : https://github.com/DorianMuzi/LinguaCE-Keyboard

Envie d'aider ? Dans l'application, vous pouvez choisir de proposer les mots que vous utilisez pour enrichir les suggestions. Rien n'est envoyé sans votre action.
