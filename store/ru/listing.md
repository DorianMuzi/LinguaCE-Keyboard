# Описание в Google Play — русский (ru-RU)

## Название (до 30)
LinguaCE Keyboard

## Краткое описание (до 80)
Чеченская клавиатура: латиница и кириллица, подсказки. Без доступа в интернет.

## Полное описание (до 4000)
Пишите по-чеченски латиницей или кириллицей на клавиатуре, созданной для этого языка.

LinguaCE Keyboard — проект экосистемы LinguaCE, которая помогает изучать и писать чеченский язык.

ПИШИТЕ ПО-ЧЕЧЕНСКИ ПРАВИЛЬНО
• Чеченский латинский алфавит: долгое нажатие на букву открывает её варианты (x → ẋ, s → ş, c → ċ, ç → ç̇, n → ŋ…).
• Кириллическая клавиатура с клавишей Ӏ (палочка).
• Клавиша КИР / LAT переключает латиницу и кириллицу; долгое нажатие — смена клавиатуры.
• QWERTY или AZERTY для латиницы.
• Цифры — долгим нажатием на верхнем ряду, как в Gboard.
• Буква w остаётся доступной для иностранных слов.

ПОДСКАЗКИ, КОТОРЫЕ УЧАТСЯ
• Подсказки слов из базового списка и из слов, которые вы вводите; обучение — только на вашем телефоне.
• Пишите без диакритики: «noxciyn» предложит «noxçiyŋ».
• Личный словарь: просматривайте, добавляйте и удаляйте слова или очищайте всё.

УДОБСТВО
• Светлая, тёмная тема или как в телефоне; клавиши низкие, обычные или высокие.
• Панель эмодзи с недавними (долгое нажатие на запятую).
• Панель инструментов: настройки, эмодзи, отмена и вставка.
• Автоматическая заглавная буква и точка двойным пробелом.
• Звук и вибрация клавиш — по желанию.
• Работает с TalkBack.

КОНФИДЕНЦИАЛЬНОСТЬ ПО ЗАМЫСЛУ
• Никаких разрешений, даже доступа в интернет: клавиатура ничего не может отправить.
• Без рекламы, аналитики и слежки.
• Открытый код (Apache 2.0): https://github.com/DorianMuzi/LinguaCE-Keyboard

Хотите помочь? В приложении можно по желанию предложить слова, которыми вы пользуетесь, чтобы пополнить подсказки. Без вашего действия ничего не отправляется.
